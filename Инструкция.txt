Для начала нам нужно установить бекенд на сервер
для этого лучше использовать Nginx вместо Apache ( прост он удобнее )

Заходим в папку с бекендом нажимаем build.bat

после билда заходим на вдс качаем: nginx, postgres, 
и все что дальше вас просит.

Мы в nginx конфигурации в /etc/nginx/sites-avaible заходим
в default и настраиваем редирект по /api/ чтобы запрос
шел на бекенд 

domain.com/чето там -> Наш фронт енд
domain.com/api/ -> http://localhost:1000/

для этого над настраивать редирект.

Загружаем бекенл на сервер но не запускаем
пока что, ибо в постгрес надо залить нашу схему и
sql конфигурацию.

Создаем базу:

psql -U postgres -h localhost -W postgres
СREATE DATABASE неймбдшки_db OWNER postgres;
\q
psql -h localhost -U postgres -d неймбдшки_db -f /путь к sql/wissend.sql

Все наша sql залита на сервер!

Запускаем бекенд, после чего запускаем фронт енд, и билдим проект
так же заливам это все по прямым ссылкам, билдим лоадер и воуля!
